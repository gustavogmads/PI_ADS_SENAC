# Alterações da versão 5

A tela do cliente passou a destacar claramente os caixas com verde, amarelo e vermelho.

## Regra das cores

Os caixas são ordenados pelo tempo estimado de espera.

- verde: caixa com menor espera;
- amarelo: caixas intermediários;
- vermelho: caixa com maior espera;
- cinza: caixa ainda sem estimativa.

Se houver empate no tempo, o sistema usa:

1. menor quantidade de produtos;
2. menor quantidade de pessoas.

## Mudanças visuais

Cada caixa agora possui:

- borda colorida;
- etiqueta com a situação;
- legenda no topo da lista.

A recomendação principal também aparece com destaque verde.
